# CV Application
The CV Application is a simple web-based tool designed to help users create a professional CV using a predefined template. Built with React, this application allows users to input their information and generate a formatted CV quickly and efficiently
##### Features
- User-Friendly Interface: The application provides an intuitive interface for users to enter their personal and professional details.
- Predefined Template: Users can create their CVs based on a structured template, ensuring consistency and professionalism.
- Live Preview: Users can see their input reflected in real-time, making adjustments as needed before finalizing their CV.
##### Techstack
- React for building iterface and generating dynamic content
- HTML/Sass for structuring and styling
